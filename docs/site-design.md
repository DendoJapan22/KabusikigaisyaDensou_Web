# 株式会社電総 コーポレートサイト — デザイン仕様（現行版）

> このドキュメントは **現在公開されているサイトの実装デザイン** を記述したものです。

## 0. デザインの核

このサイトのデザインは、相反する2つの要求を同時に満たすために設計されています。

| 要求 | 出所 | 実装 |
|---|---|---|
| 30年の職人であることを、誇張せずに信じさせる | 元の要件 | 明朝の縦組み、漢数字、余白の広さ、抑えた文字組み |
| 堅苦しくない、少し楽しめる雰囲気にしたい | クライアントの希望 | 鮮やかな色紙テクスチャ、通電アニメーション、大きな数字 |

つまり **「硬派な骨格に、鮮やかな色を面で乗せる」**。
線や文字で遊ばず、**色は面（ベタ塗り・カード・帯）でだけ遊ぶ**のがルールです。

キーワード：
`職人` `夕暮れの灯り` `方眼紙` `通電` `濃紺と黄` `落ち着いているが、退屈ではない`

## 1. カラーパレット

### ブランドカラー（3色）

| 役割 | 色 | HEX | 用途 |
|---|---|---|---|
| **主役** | 黄 | `#F7CE2E` | ラベルの下地、ハイライト、リンク、太い線。**面で使う** |
| **構造** | 濃紺 | `#08192B` | 文字、フッター、帯セクション、ヒーロー左パネル |
| **地** | 白 | `#FFFFFF` | 背景 |

### 補助色

| 名前 | HEX | 用途 |
|---|---|---|
| アンバー（ロゴ由来） | `#EE9800` | 細い線、小さな印、アイコンの一点 |
| ネイビー700 | `#123A5E` | 副次的な面 |
| ブルー500 | `#1B4D80` | 本文中のリンク |
| ミスト | `#E8EDF2` | 明るいセクション背景 |
| 銅（ヒーロー限定） | `rgba(184,115,51,.55)` | ヒーローの「導線」1px 縦線のみ |

### 事業内容カードの色紙（5色）

方眼紙テクスチャに乗る背景色。**このサイトで最も彩度が高い場所**です。

| 領域 | HEX |
|---|---|
| 電気設備 | `#F5D23C`（黄） |
| 空調設備 | `#75BFEB`（水色） |
| 換気・ダクト | `#7BD495`（緑） |
| 弱電・通信 | `#BBA0EB`（藤） |
| 消防・防災 | `#F59B86`（サーモン） |

> これらは「カード」という限定された枠の中でだけ使われます。
> **写真素材にこの5色を持ち込まないでください。** 写真は黄・濃紺・白の3色に寄せます。

### 色の使い方の原則

1. 濃紺は**構造**、黄は**強調**、白は**呼吸**。3色の役割を混ぜない
2. 黄は「小さく、はっきり」。広い面に薄く敷かない
3. グラデーションは原則使わない（例外：電球の発光、ヒーローの導線の流れ）
4. 影はほぼ使わない。奥行きは**重なりと余白**で出す

## 2. タイポグラフィ

| 用途 | 書体 | 指定 |
|---|---|---|
| 見出し・キーコピー | **Noto Serif JP**（明朝） | weight 400 / 500 のみ |
| 本文・UI | **Zen Kaku Gothic New**（ゴシック） | weight 400 / 500 / 700 |
| 数字・英字ラベル | **Anton** | weight 400 のみ（**太字指定禁止**。フォールト・ボールドになる） |

### 組みのルール

- **ヒーローコピーは縦組み**（`writing-mode: vertical-rl`）。右列から左列へ進む
- 情緒的な数字は**漢数字**（「三十年」）。事実としての数字は**Antonのアラビア数字**（「30年」「1都4県」）
- 本文 16px / 行間 1.9
- 見出し 32px / 明朝 weight 500 / 行間 1.5
- 英字ラベルは Anton・13px・字間 `.2em`・大文字・**黄色の下地に濃紺の文字**
- 段落は短く。1文が長くなったら改行で切る

---

## 3. レイアウト

- コンテナ最大幅 **1140px**、左右余白 24px
- 余白は **8の倍数**（8 / 16 / 24 / 32 / 48 / 64 / 96 / 128）
- セクションの上下余白は **3段階だけ**：`64px`（詰め） / `96px`（標準） / `128px`（帯）
- グリッドは**意図的に非対称**。等分割の3カラムを避け、`1.35fr 1fr 1fr` のような比率を使う
- 角丸は控えめ。例外はヘッダーの白いプレート（右下だけ `44px`）とピル型ボタン

### 印象的な構造要素

- **ヘッダーの白いプレート**：左上に置かれた白い板。右下だけ大きく丸まっていて、ロゴが載る。写真の上に切り抜きのように重なる
- **信頼バー**：ヒーロー下端に貼り付く3項目の横帯。常に数字が見えている
- **ヒーローの左右分割**：左が濃紺のベタ面（縦書きコピー）、右が夕暮れの写真
- **導線の1px 縦線**：ヒーローのコピー右側に走る細い銅色の線。読み込み時に光が上から下へ一度だけ流れる

## 4. モーション

### 基本
- イージング `cubic-bezier(.4, 0, .2, 1)`
- スクロール連動（IntersectionObserver）で、画面に入ったら一度だけ動く。繰り返さない
- `prefers-reduced-motion: reduce` で全アニメーションを停止

### 固有のモーション

| 名前 | 動き |
|---|---|
| **通電（ヒーロー）** | 1px の縦線を、光の帯が上から下へ 1.4秒かけて一度だけ通過する。その後コピーが右列→左列の順にフェードイン |
| **回路の通電（事業内容）** | 横一直線のSVG上を光の点が走り、通過した5つのノードが順に黄色く点灯する |
| **エコー（見出し）** | 見出しの文字が左から右へワイプで現れる。同じ文字を少しずらしてアンバーの半透明で重ねてある（残像） |
| **カードの入場** | 下から26px、110ms ずつ遅らせて1枚ずつ立ち上がる |

**モーションの思想**：電気が通る、灯りがつく、という現象そのものをアニメーションにしています。装飾的に動かすのではなく、**「通電」というひとつの比喩で全部を統一**しています。

## 5. 写真・画像の扱い

### トーン

このサイトの色の基準はヒーロー写真（夕暮れの住宅街）です。すべての画像はこれに寄せます。

- **時間帯**：夕暮れ〜ブルーアワー、または早朝。真昼の直射日光は避ける
- **光**：自然光。窓や照明から漏れる暖色の光が、冷たい紺色の空間にぽつぽつと入る
- **彩度**：低め。ただし黄色い光源だけは強く出す
- **質感**：わずかなフィルムグレイン。デジタル的なツヤ・CG光沢を出さない
- **構図**：引き。余白を大きく取る。被写体を画面いっぱいに詰めない

### 画像に絶対入れないもの

```
人物、顔、手、作業員、文字、ロゴ、看板、透かし、ナンバープレート、
配線のクローズアップ、分電盤の内部、端子台、ケーブル束、
過剰な彩度、HDR、CG光沢、レンズフレア、ネオン、サイバーパンク、
ごちゃついた背景、ストックフォト的な笑顔
```

> 人物と配線の2つを外すだけで、AI生成画像の破綻はほぼ消えます。
> そしてこの2つこそ、このサイトで最もAI生成が許されない要素です（`site-contents.md` §6 参照）。

### 各スロットの被写体方針

**事業内容の5枚** — 「工事中」ではなく **「仕事が終わったあとの静かな空間」** を撮る。
- 電気：夕方、照明がついたばかりの集合住宅の共用廊下
- 空調：早朝、清潔なコンクリート屋上に並ぶ室外機を、ローアングルで幾何学的に
- 換気：飲食店の高い天井を横切る、露出したスパイラルダクト
- 弱電：写真ではなく図像。濃紺の地に細い黄色い線で描いた同心円状の電波
- 防災：暗い廊下の天井で静かに光る誘導灯ひとつ

**対応エリアの5枚** — 引きの情景。ランドマークは1つだけ、あとは空と街並み。
- 神奈川：ブルーアワーの横浜ウォーターフロント、灯りがつき始めた頃
- 東京：夕暮れの俯瞰。低層の建物が密集し、窓に暖色の灯りが点在する
- 千葉：夕方の海沿いの静かな町。低い建物と広い空
- 山梨：夜明け、霧の向こうに富士山。手前に小さな町
- 静岡：午後遅く、茶畑の斜面と点在する家々

**ヘッダー3枚** — 上に白文字が乗るので、**画面の右側を大きく空ける**構図で。
- 料金：濃紺の机の上のノート・鉛筆・折尺を真上から。右側は空
- 問い合わせ：濃紺の壁に、左上から差す暖色の光ひとつだけ。他は何もない
- 仕事の内容：夜明けの建設中マンションのシルエット。足場の線が空に浮かぶ

**採用・会社の3枚** — 人は写さず、**人がいた痕跡**だけを撮る。
- 使い込まれた革の工具ベルトと工具を、朝の光の中で真上から
- 早朝の静かな住宅街に停まった白い作業車（文字・ナンバーなし）
- 夜のデスクに置かれたスタンドライトと丸めた図面。暖色の光だまりと深い影

## 8. 技術的な制約

- 静的HTML/CSS/JS。ビルド工程なし
- 画像は **WebP + JPEG フォールバック**（`<picture>` / CSS `image-set()`）で配信
- フォントは Google Fonts の unicode-range 自動サブセット
- 納品形式：**PNG または JPEG の元データ**（変換はこちらで実施）
- 推奨解像度：長辺 2000px 以上
