|---|---|
| 業種 | 電気設備工事業（電気工事・空調工事が主力） |

| 主力事業 | 建設会社経由での賃貸マンション等、新築集合住宅の電気配線工事 |
| 副次事業 | 個人向けエアコン取付（B2C） |
| 対応エリア | 神奈川県・東京都・山梨県・千葉県・静岡県 |

### サイトの目的（クライアント申告）

1. 問い合わせ・依頼を増やしたい
2. 求人・人材募集をしたい
3. 名刺代わりに使いたい
4. 会社を信頼してもらいたい
5. 実績と施工例を見せたい

### 目的の優先順位（提案）

主力事業は建設会社とのコネクションで受注しているため、サイトが直接受注を生む構造ではない。
実際の役割は以下の順で設計する。

- **第1層：信頼の担保（3・4）** — サイトの土台。会社概要・資格・登録番号・30年の経歴で構成
- **第2層：実績提示（5）** — 第1層を裏付ける根拠として機能させる
- **第3層：問い合わせ獲得（1）** — 上2層が成立して初めて機能する
- **別動線：採用（2）** — 読み手が全く異なるため独立ページ＋専用導線

→ 構成としては「信頼担保の本体」＋「採用ページ」の二階建て、その外側に「B2Cエアコン取付」を小さくぶら下げる形。

## 1. 事業内容の整理

ヒアリングでは「電気系」と一括りに語られたが、写真および聞き取りから実態は以下5領域にまたがる。
サイト上ではこの粒度まで分解して記載する（同業他社サイトに対する情報量の優位になる）。

### ① 電気設備工事（主力）

- 新築集合住宅の屋内配線工事一式
- 引込・計器盤設置、主幹ブレーカー・漏電遮断器の施工
- 住戸用分電盤の設置・回路構成
- 屋外プルボックス・配管工事
- 照明器具、コンセント、スイッチの設置
- 専用回路の増設、100V/200V切替、ブレーカー容量変更

### ② 空調設備工事（主力）

- 業務用エアコンの設置・入替
- 冷媒配管、真空引き、気密試験
- 電装部の結線・試運転調整
- 室外機の基礎・架台設置
- 家庭用エアコンの取付・移設（B2C領域）

### ③ 換気・ダクト工事

- スパイラルダクトの施工・吊り込み
- 店舗厨房の排気ダクト
- 換気扇・レンジフード

### ④ 弱電・通信設備

- テレビ共聴設備（CS/BS/CATVブースター等）
- 集合住宅用インターホン
- LAN配線

### ⑤ 消防・防災設備

- 非常警報設備（押しボタン・音響装置）
- 誘導灯

> **注記**：③〜⑤は写真から実施が確認できるが、本人の主観では「電気工事」に含めて語られている可能性が高い。
> 記載前に「これも自社で対応可能か／協力会社に出しているか」を確認すること。

### 3-4. 施工事例・実績紹介 `/works/`

**⚠ 掲載前の重要確認事項**

現時点で提供されている写真は前職または下請け現場のものである可能性が高い。以下を必ず確認する。

- 撮影時期と、当時の立場（自社受注か、勤務先の現場か）
- 元請・施主からの掲載許可の有無
- 許可が取れない場合の代替方針

**許可が取れない場合の逃げ方**
「施工実績」ではなく「**対応可能な工事内容**」として、機器のアップ写真中心に構成する。
物件が特定されず、かつ技術的な説得力はむしろ上がる。

**写真の加工が必要な箇所**

- 建物名の銘板（物件が特定される）
- 電力量計の製造番号
- 車両ナンバー
- 集合ポストの部屋番号
- スクリーンショット由来のUI・ステータスバー

**事例フォーマット**

| 項目 | 例 |
|---|---|
| 工事種別 | 電気設備工事／空調設備工事 等 |
| 物件種別 | 賃貸マンション（新築）／店舗（内装工事）／戸建て |
| エリア | 神奈川県◯◯市 ※市町村レベルまで |
| 工期 | ◯日間 |
| 施工内容 | 箇条書き |
| 写真 | 施工中・完了後 |

**カテゴリ絞り込み**：工事種別 × 物件種別 × エリア

### 3-5. 料金・費用の目安 `/price/`

B2B案件は個別見積のため、このページは実質**B2C（エアコン取付）向け**として設計する。

| ブロック | 内容 |
|---|---|
| 基本料金 | 家庭用エアコン標準取付、取外し、移設 |
| 追加工事の料金 | 下記参照 |
| 料金に含まれるもの/含まれないもの | 明示 |
| お見積りの流れ | 現地調査は無料か有料か ※要確認 |
| 法人のお客様へ | 「個別見積」の旨と問い合わせ導線 |

**追加工事の項目（差別化の核）**

量販店の取付では「対応不可」「別業者手配」になる作業を、電気工事士が同日に完結できる点が唯一の勝ち筋。
以下を相場込みで記載できると強い。

- 専用回路の増設（分電盤からの配線）
- 100V ⇔ 200V の電圧切替
- ブレーカー容量の見直し
- 隠蔽配管
- 配管延長（4m超）
- 化粧カバーの取付
- 室外機の特殊設置（屋根置き・壁面金具・二段置き）
- 高所作業

> **クライアントへの説明事項**：B2Cのエアコン取付をWeb検索単独で獲得するのは現実的に難しい。
> この領域はくらしのマーケット、ミツモア等のプラットフォームが検索面を押さえており、新規ドメインの参入余地は小さい。
> 本ページの役割は「プラットフォーム経由で興味を持った人が社名で検索した際の信用担保」と位置づける。

### 3-7. お客様の声 `/voice/`

**現状の課題**：新設法人のため、社名義での声はまだ集まっていない可能性が高い。

**対応方針（優先順）**

1. 既存の取引先（建設会社）から短くてもコメントをもらう。実名困難なら「建設会社 ご担当者様」等の匿名表記
2. B2C案件を数件こなした後に随時追加していく前提で、枠だけ用意
3. 声が集まるまでは、ページ自体を公開せず（またはトップの導線を非表示にして）、代わりに「対応の姿勢」を示すコンテンツで代替

**フォーマット**

- お客様の属性（法人／個人、業種、エリア）
- 依頼内容
- 評価コメント
- 施工写真（可能であれば）

> 空のページを公開すると逆効果になるため、コンテンツが揃うまでの公開判断をクライアントと握ること。

## 4. 要確認事項リスト

次回ヒアリングで埋めるべき項目。★は記載の可否がサイトの説得力を大きく左右する。

### 資格・許認可

- ★**電気工事士の種別（第一種／第二種）と取得年**
  → 写真にある125A主幹の引込盤や集合住宅の受電まわりは本来第一種の領域。30年のキャリアなら第一種の可能性が高いが、確認せずに書けない
- ★**電気工事業登録番号**（資格とは別に事業者として必要な手続き。業界の通例として記載する）
- 建設業許可の有無と業種
  → 創業直後は要件的に未取得の可能性。その場合は500万円未満の工事が守備範囲となり、B2Bの訴求を大規模新築ではなく改修・部分工事寄りに振る必要がある
- 冷媒フロン類取扱に関する資格（空調をやるなら必要）
- 消防設備士、工事担任者の有無
- 賠償責任保険の加入状況

### 事業・実績

- 換気・弱電・防災は自社施工か、協力会社に出しているか
- 主要取引先の構成と、社名掲載の可否
- 新築と改修の比率
- 対応エリア5県は実績か対応可能範囲か。B2B/B2Cで範囲は異なるか

### 写真

- ★**撮影時期と当時の立場（自社受注か前職か）**
- ★**元請・施主からの掲載許可**
- 追加撮影の可否

### 料金

- エアコン取付の基本料金と追加工事の相場
- 現地調査・見積は無料か
- 出張費のエリア加算

### 採用

- ★**未経験可否**
- ★**給与レンジ**
- 勤務時間、休日、社会保険、資格取得支援
- 採用の緊急度

### その他

- 「サービス」と「仕事の内容」の意図の違い
- B2Cを本気で伸ばしたいのか、副次的な位置づけか
- 会社概要の各項目（社名・所在地・電話番号・設立年月）

## 5. クライアントへの説明が必要な事項

期待値のズレを防ぐため、着手前に共有しておく。

1. **主力のB2B案件はサイトから直接受注されない**。役割は元請担当者が調べた際の信用担保、および新規元請開拓の武器
2. **B2Cのエアコン取付はWeb検索単独では獲得困難**。プラットフォームが検索面を押さえている。サイトは受け皿として機能させる
3. **写真の掲載には元請・施主の確認が必要**。取れない場合は構成を変更する
4. **お客様の声は初期段階では埋まらない**。公開タイミングの判断が必要
5. **資格・登録番号が書けるかどうかで説得力が大きく変わる**。ここは必ず確認したい
